Hotspots to resolve

    Ubiquitous language

    Automation ladder
    Rule → workflow → classic ML → single GenAI call → agent → multi-agent. Use the lowest step that does the job.
    Process owner
    Person in a business unit who requests and is accountable for an automation.
    Triage
    Short decision tree run before anything is built. Its result is the recommended ladder step.
    Output similarity / path similarity
    How alike an agent's replies are, and how alike its tool-call sequences are, across runs. Computed with simple statistics from logs.
    Uniform agent
    An agent whose runs have become near-identical. It behaves like a workflow and costs like an agent.
    Conversion
    Turning the frequent paths of a uniform agent into a workflow. The agent keeps only the exceptions.
    Exception scope
    The cases an agent still handles after conversion.
